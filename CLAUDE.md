# Livetrack — Guía para Claude

App de una sola página (`index.html`) para compartir y ver ubicación en tiempo
real entre particulares. Desplegada en Vercel (`vercel.json`).

## Reglas de trabajo

1. **Subir directo a `main`.** Sin ramas ni PRs salvo que se pida explícitamente.
2. **Documentar SIEMPRE en `docs/BACKLOG.md`:** cualquier cambio (fix, feature,
   bug encontrado) se agrega como entrada en `docs/BACKLOG.md` (crearlo si no
   existe) — causa real, qué se cambió, y cómo se verificó.
3. **Cerrar con botones** (`AskUserQuestion`) proponiendo el siguiente paso.
4. Idioma de trabajo: **español**.
